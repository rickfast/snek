# Roadmap

The ordered roadmap below records completed and active milestones. Completion does not mean
all of Python is supported. Local static modules now work; current limits include
dynamic imports and module globals,
filesystem/network APIs, concurrent task spawning, and a portable GC component
boundary. Package registry publication remains a separate release step.
